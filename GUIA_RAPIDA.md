## 🔴 PARA RH / GDH

### 1. Acceder al Panel RH

```
1. Login con usuario GDH
2. Menú lateral → Buscar "Panel RH"
3. ¡Listo! Ya ves el panel completo
```

### 2. Subir Archivo de Tareo

**Método 1: Drag & Drop (más rápido)**
- Arrastra el archivo Excel al área punteada
- Click en "Sincronizar"
- Espera a que se procese

**Método 2: Click en el área**
- Click en el área de upload
- Selecciona archivo de tu computadora
- Click en "Sincronizar"

### 3. Entender las Estadísticas

Una vez subido el archivo:

```
┌─────────────────────────────────┐
│  ESTADÍSTICAS DE TAREO ACTUAL   │
├─────────────────────────────────┤
│ 🌅 Mañana: 45 registros         │
│ 🌤️  Tarde:  38 registros        │
│ 🌙 Noche:  22 registros         │
│ 🏖️ Vacaciones: 8 registros      │
│ ❌ Faltas: 5 registros           │
│ 📋 Licencias: 2 registros       │
└─────────────────────────────────┘
```

**¿Qué significa?**
- **Mañana/Tarde/Noche:** Turnos en que trabajaron
- **Vacaciones:** Días de descanso autorizado
- **Faltas:** Inasistencias
- **Licencias:** Permisos/incapacidades

### 4. Ver Tabla Completa de Tareo

Si necesitas ver más detalles:
- Menú → "Registro tareo"
- Buscar por DNI o nombre
- Editar comentarios si es necesario

### 5. Historial de Archivos Cargados

En el Panel RH verás:
- Fecha del último archivo procesado
- Cantidad de registros procesados hoy
- Estadísticas en tiempo real

## 👤 PARA AUXILIAR

### 1. Acceder a Mi Tareo

```
1. Login con usuario Auxiliar
2. Menú lateral → Buscar "Mi Tareo"
3. ¡Verás tu calendario de asistencia!
```

### 2. Entender el Calendario

```
┌─ MAYO 2026 ─┐
│ Dom Lun Mar  │
├──────────────┤
│  1 🌅  2 🌤️   │ (números = días)
│  3 🌙  4 🌙  5│ (íconos = turno)
│  ...........│
│ 28 🏖️ 29 30 │
└──────────────┘

🌅 = Turno Mañana
🌤️  = Turno Tarde
🌙 = Turno Noche
🏖️ = Vacaciones
❌ = Falta
📋 = Licencia
```

### 3. Navegar entre Meses

- **Botón ◀️** (izquierda) = Mes anterior
- **Botón ▶️** (derecha) = Mes siguiente

### 4. Ver Detalles de un Día

- **Haz clic en el número del día** en el calendario
- Verás tooltip con el tipo de asistencia
- Si hay comentarios de RH, también aparecen

### 5. Resumen del Mes

En el panel derecho ves:

```
📊 RESUMEN DEL MES
─────────────────
🌅 Mañana:     12 días
🌤️  Tarde:      10 días
🌙 Noche:       8 días
🏖️ Vacaciones:   2 días
❌ Faltas:       1 día
📋 Licencias:    0 días
─────────────────
Total días:     33
```

### 6. Tabla de Registros

Scroll down para ver tabla con:
- **Fecha:** cuándo fue
- **Turno:** qué tipo
- **Comentario:** notas de RH (si las hay)

## 🆘 PREGUNTAS FRECUENTES

### ❓ "¿Por qué no puedo ver el Panel RH?"
**Respuesta:** Solo usuarios con rol `GDH` lo ven. Verifica tu rol con tu admin.

### ❓ "¿Por qué el archivo no se subió?"
**Respuesta:** Verifica:
- Debe ser archivo `.xlsx` o `.xls`
- No debe tener más de 10MB
- Debe tener el formato correcto con columnas

### ❓ "¿Mis datos se actualizan en tiempo real?"
**Respuesta:** Sí, después de subir archivo se recalculan automáticamente.

### ❓ "¿Por qué veo un día en blanco?"
**Respuesta:** Significa que no hay registro para ese día (no trabajaste o no se registró aún).

### ❓ "¿Puedo editar mi tareo?"
**Respuesta:** No, solo RH puede editar. Si hay error, contacta a GDH.

### ❓ "¿Dónde veo mis vacaciones aprobadas?"
**Respuesta:** En "Mi Tareo", busca el ícono 🏖️ en el calendario.

## 🐛 SI ALGO NO FUNCIONA

### Solución 1: Recargar la página
```
Windows/Linux: Ctrl + R
Mac: Cmd + R
```

### Solución 2: Limpiar caché
```
Windows/Linux: Ctrl + Shift + Delete
Mac: Cmd + Shift + Delete
```

### Solución 3: Cerrar sesión y reloguear
- Click en tu avatar (arriba derecha)
- "Cerrar sesión"
- Login de nuevo

### Solución 4: Contactar a IT
Si persiste el problema, reporta a:
- **Responsable:** GDH
- **Incluir:** screenshot del error, qué intentabas hacer
